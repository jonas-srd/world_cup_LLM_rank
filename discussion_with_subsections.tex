\section{Discussion}
\label{sec:discussion}

\subsection{Forecasting Performance Is a Property of the Full System}
\label{sec:discussion-system}

\begin{draftbullets}
  \item \textbf{Forecasting systems, not model names alone.} The metric-dependent leaderboard and the
  access effect show why a model identifier is an incomplete description of a deployed forecaster.
  Model, condition, and their interaction all contribute to observed variation. Deployment effects
  can be comparable in magnitude to between-model variation even though the current data do not
  support a claim that conditions dominate every model difference. Comparisons of ``LLM forecasting
  ability'' should therefore specify not only the underlying model and version, but also the
  information environment, elicitation procedure, forecast horizon, output validation, and aggregation
  rule under which the forecast was produced.

  \item \textbf{Information has a measurable benefit and a measurable price.} The open-book T--24h
  benefit survives timing and match-deletion checks, and the directional snapshot pattern is
  consistent with changing information becoming useful nearer kickoff. Yet tool availability does
  not create a standardized intervention: providers differ in whether they search, how much context
  they retrieve, and the latency, token, and financial cost they incur. Open-book performance is thus
  an end-to-end property of the model--retrieval configuration rather than a clean measure of either
  parametric knowledge or retrieval quality in isolation. Reporting forecast gains without search
  compliance and resource use would conceal an important part of the deployment trade-off.
\end{draftbullets}

\subsection{Elicitation, Confidence, and Shared Forecast Structure}
\label{sec:discussion-structure}

\begin{draftbullets}
  \item \textbf{Elicitation changes structure before performance.} Reversing score and probability
  elicitation barely changes average forecast quality, but it changes draw scorelines, exact 1--1
  predictions, and the relation between score and outcome modes. The absence of an aggregate Brier
  improvement should therefore not be interpreted as evidence that the prompts are behaviorally
  equivalent. Prompt interventions can reshape the joint distribution of structured outputs while
  leaving a headline metric nearly unchanged, which makes semantic and distributional audits necessary
  alongside performance comparisons.

  \item \textbf{Decisions, probabilities, and confidence are distinct outputs.} Reliability differs by
  outcome, self-reported confidence tracks relative difficulty without being a calibrated probability
  of correctness, and strong tournament picks coexist with a shared Group~K miss and invalid sums of
  semifinal marginals. These observations caution against treating every numerical field emitted by
  an LLM as the same kind of uncertainty statement. A categorical choice, a class-probability vector,
  marginal inclusion probabilities, a modal scoreline, and an overall confidence value obey different
  mathematical constraints and require separate validation and interpretation.

  \item \textbf{A correlated crowd offers limited robustness.} Models rank matches similarly while
  retaining small probability-level differences. Shared web access does not detectably reduce this
  diversity, but the high pairwise correlations indicate that nominally different model families are
  exposed to substantial common signal and common error. Same-cell averaging mechanically improves
  on the average member but does not reliably beat individual models. Ensembling is therefore a modest
  robustness mechanism in this setting, not an independent forecasting oracle; larger gains would
  likely require genuinely different information sources, modeling assumptions, or explicit
  diversity-inducing procedures rather than additional highly correlated LLM forecasts.
\end{draftbullets}

\subsection{Implications for Live Benchmarking and Scope}
\label{sec:discussion-benchmarking}

\begin{draftbullets}
  \item \textbf{Prospective collection exposes operational outcomes.} Fable's missing calls,
  incomplete search compliance, validation records, latency, cost, and rationale coverage are
  scientifically meaningful properties that a retrospective leaderboard would hide. A model that
  forecasts well when it returns a valid response but fails frequently is not interchangeable with a
  slightly less accurate system that executes reliably. Live benchmarks should therefore preserve
  stable prediction keys, scheduled and actual timestamps, raw prompts and responses, tool traces,
  explicit missingness policies, and frozen data snapshots. Tool-enabled conditions should be analyzed
  by assigned access under an intent-to-treat principle, with observed tool use reported separately,
  so that provider compliance does not silently redefine the experimental groups after collection.

  \item \textbf{Scope, limitations, and transfer.} The evidence comes from one tournament with 104
  matches, one deterministic sample per experimental cell, provider-specific retrieval, incomplete
  Fable coverage, sparse late-stage strata, and only 15 tournament-level questions. Football provides
  objective and rapidly resolved targets, but it also has domain-specific score distributions,
  information ecosystems, and incentives. Rationale labels describe observable generated text rather
  than hidden reasoning, causal evidence use, or factuality. No external candidate currently passes
  the provenance and reproduction gate, so we make no comparative claim against betting markets,
  Opta, or classical statistical models. Repeated prospective deployments across tournaments and
  domains, together with time-aligned external baselines, are needed before generalizing the observed
  access, prompting, calibration, or diversity effects. The benchmark evaluates forecasts and should
  not be interpreted as wagering advice.
\end{draftbullets}
