# Country flags

These flags are used by `rq6_tournament_questions`.

Source: [`flag-icons` 7.5.0](https://github.com/lipis/flag-icons), licensed MIT.
The 4:3 SVG assets were downloaded on 2026-07-24 and rendered to 160 x 120 PNG
files for Matplotlib.

Mappings:

- Argentina: `ar.png`
- Belgium: `be.png`
- Brazil: `br.png`
- Colombia: `co.png`
- England: `gb-eng.png`
- France: `fr.png`
- Germany: `de.png`
- Mexico: `mx.png`
- Netherlands: `nl.png`
- Spain: `es.png`
- Switzerland: `ch.png`
- United States: `us.png`
